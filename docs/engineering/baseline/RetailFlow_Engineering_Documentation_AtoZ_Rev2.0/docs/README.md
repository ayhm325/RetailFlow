# RetailFlow Docs-as-Code

هذا المجلد يحتوي فصول الدليل الرئيسي مفصولة لسهولة المراجعة عبر Pull Requests. المرجع الكامل هو `../Master_Engineering_Handbook_AR.md`.

## قواعد التحرير
- لا تعدّل الحالة من Proposed إلى Implemented دون كود واختبار قابلين للتتبع.
- لا تعِد استخدام FR/UC/BR/ADR IDs.
- حدّث registers وdiagrams وOpenAPI في نفس التغيير الذي يغيّر السلوك.
- سجّل baseline commit وبيئة الاختبار وأرقام النتائج.
